# VEA Creations — Vercel React Frontend

## Stack
- React + Vite
- CSS
- Vercel static deployment
- No PHP, database, server or API required

## Main store
`/`

## Private admin route
`/atelier-console-7x9q`

Demo PIN: `VEA2026`

The admin is intentionally not linked in the normal navigation. Because this is a frontend-only app, this is NOT real security: the route/PIN and product data are shipped to the browser. Do not use this client-side admin for secrets or sensitive data.

## Admin features
- Add / edit / delete products
- Price and category
- Image path or URL
- Video path or URL
- Instagram Reel/Post URL
- Description
- Search
- Export/import products JSON
- Set WhatsApp business number

## Deploy to Vercel
Build command: `npm run build`
Output directory: `dist`
